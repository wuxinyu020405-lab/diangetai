## 1. 顶栏 / 底部常驻区

| 旧版 | 新版位置 |

| ⏸ 暂停播放 | 直播台 · 正在播放卡片 |
| ⏭ 切歌 | 直播台 · 正在播放卡片 |
| 四个挂件地址 + 复制 | OBS 挂件页 · 顶部「挂件地址」 |
| 音频驱动状态 | 运行日志页 |

| 首屏默认停在「日志」页 | 新版默认停在「直播台」（有意调整，不是漏设置） |
