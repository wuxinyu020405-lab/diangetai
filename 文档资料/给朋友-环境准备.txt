点歌台 v1.2.9.1 源码 · 给朋友的环境准备说明
================================================

这是源码包（不是直接能双击运行的软件）。要改功能或自己打包，按下面做。


一、你会拿到什么
------------------------------------------------
- 点歌台拆分\      主源码（Python）
- 点歌台.iss / 点歌台.spec   安装包与打包配置
- README.md / 使用说明.md / 打包说明.md   说明文档
- 踩坑实录.md / 工作日志.md / 点歌台项目交接_v1.2.9.md   历史与现状
- requirements.txt   Python 依赖清单
- LICENSE            GPL-3.0-or-later

刻意没有放进来的（出于隐私/体积）：
- config.json / credential.json（你的登录凭据，需要自己扫码登录生成）
- my_songs\（自己录的歌）
- music_cache\（下载缓存）
- 抖音签名组件 sign.js（版权原因，需要的话自己找）

注意：程序里的 config.json 内容是加密的（Windows DPAPI），
换一台电脑解不开，所以必须自己重新登录，不能拷配置文件。


二、环境准备（Windows 10/11 x64）
------------------------------------------------
1. 装 Python 3.12（必须是 3.12，winsdk 只有 <=3.12 的 wheel）
   到 python.org 下载安装，勾选 "Add Python to PATH"。

2. 在工作目录建虚拟环境并安装依赖：
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install --upgrade pip
   .venv\Scripts\python.exe -m pip install -r requirements.txt

3. 额外装 blivedm（B站弹幕库，必须从 GitHub 装）：
   .venv\Scripts\python.exe -m pip install --no-deps "blivedm @ https://github.com/xfgryujk/blivedm/archive/refs/heads/master.tar.gz"

4. 装 pywebview（登录窗口用）：
   git clone --depth 1 https://github.com/r0x0r/pywebview _pywebview_src
   .venv\Scripts\python.exe -m pip install ./_pywebview_src
   注意：必须用 git clone，不能用下载 zip，否则 setuptools_scm 定不了版本号会构建失败。


三、跑起来
------------------------------------------------
开发模式：
   cd 点歌台拆分
   ..\.venv\Scripts\python.exe main.py

自检（排错用）：
   ..\.venv\Scripts\python.exe main.py --selftest
   会生成 自检报告.txt，里面有完整诊断。

打包成 exe（改成你自己想要的软件）：
   按 打包说明.md 里的命令走，用 点歌台.spec：
   .venv\Scripts\python.exe -m PyInstaller 点歌台拆分\点歌台.spec --noconfirm
   产物在 dist\点歌台\，要整个文件夹一起用，只拷 exe 打不开。
   打包脚本会自动复制 .NET 运行时，目标机器不用装 Python/.NET。


四、先读这几个文件再动手
------------------------------------------------
- 踩坑实录.md      已经踩过的坑，动代码前必看（尤其 pygame.mixer 单例那个）
- 工作日志.md      当前需求池与历史改动
- 点歌台项目交接_v1.2.9.md   架构与模块职责

版本单一来源：点歌台拆分\version.py，改版本只改这里。
发版流程：改版本号 -> 提交 -> 打 tag v版本号 -> CI 自动打包发布。
