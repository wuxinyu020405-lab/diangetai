# 扫码点歌台 v1.0 依赖清单
# 环境：Python 3.12.10 (venv)  |  更新：2026-10-29  |  平台：Windows 10/11 (win_amd64)
#
# ── 安装步骤 ──────────────────────────────────────────────────────────
#   python -m venv .venv
#   .venv\Scripts\activate
#   pip install -r requirements.txt --only-binary=:all:
#   pip install --no-deps "blivedm @ https://github.com/xfgryujk/blivedm/archive/refs/heads/master.tar.gz"
#   pip install "pywebview @ https://github.com/r0x7/pywebview/archive/refs/heads/master.tar.gz"
#
# ── 为什么 blivedm 要单独用 --no-deps 装 ─────────────────────────────
#   源码用的是 blivedm 老 API：BLiveClient.set_handler + 同步 _on_danmaku。
#   - PyPI 上的 blivedm 0.1.0/0.1.1 是重写后的 async 版（add_handler），与源码不兼容；
#     且钉死 aiohttp==3.7.4 / brotli==1.0.9（无 cp312 wheel）。
#   - 只有 GitHub master（v1.1.7）仍是 set_handler + 同步 handler。
#   - 实测 master 在 aiohttp 3.14.5 + brotli 1.2.1 下正常，故 --no-deps 安装。
#
# ── 为什么 pywebview 从 GitHub master 装 ─────────────────────────────
#   登录用 pywebview 内嵌 WebView2（替代已废弃的 Selenium）。
#   开发机当前 venv 装的是本地 master 快照（版本显示 0.0.0，原目录已不在）。
#   PyPI 的 6.2.1 同为 6.x 系，接口一致，但打包验证过的是 master——
#   重建环境后请先跑 `python 点歌台拆分\main.py --selftest` 确认登录组件可用。
#
# ── winsdk 注意 ───────────────────────────────────────────────────────
#   winsdk 是预发布版，wheel 最高 cp312 → 本项目固定 Python 3.12。
#   pip 默认不装预发布版，故必须显式写 ==1.0.0b10。
#
